# Personal Portfolio Website

## About the Project

This is my personal portfolio website created to showcase my
education, technical skills, projects, certifications, interests,
and contact information.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Personal introduction
- Education details
- Technical skills
- Projects section
- Certifications and achievements
- GitHub and LinkedIn links
- Contact section
- Marksheets viewing links
- Responsive design for mobile and desktop
